# Documentation

This directory contains the full documentation hierarchy for the Atlas platform.

- `architecture/` – High‑level system architecture, component responsibilities, data flow, failure‑recovery, and communication details.
- `design/` – Detailed design specifications for jobs, tasks, workers, scheduling, retries, heartbeats, state machines, consistency, and idempotency.
- `api/` – REST and gRPC API contracts.
- `database/` – Database schema and state‑management documentation.
- `operations/` – Local development, Docker usage, configuration, and troubleshooting guides.
- `decisions/` – Architecture decision records (ADRs).

Each subdirectory contains a `README.md` that outlines its purpose and links to the individual documents.
